# remote-env

给 Agent 用的远程服务器协作仓。Agent 不能直连服务器，通过本仓与用户协作：

**Agent 写命令 → 用户在服务器上执行 → 用户把结果 push 回来 → Agent 读取分析。**

仓库是公开的，服务器上匿名 `clone` / `pull` 即可，无需配置凭据。

## 目录结构

```
remote-env/
├── cmd.sh        # 待执行命令集，Agent 每次覆盖
└── 184/          # 以服务器 IP 末段命名，如 184、32、84
    └── tmp/      # 执行结果日志，按时间戳落盘
```

每个 `<server>/` 目录代表一台具体服务器，可存放该机器的说明文件；`tmp/` 只放执行日志。

## 工作流

1. **Agent 写命令**
   修改根目录的 `cmd.sh`：把 `SERVER` 设成目标服务器（如 `184`），把命令写进标记区间。
   始终复用这一个文件，每次整体覆盖，不新建脚本。

2. **用户在服务器上执行**
   ```bash
   git pull && bash cmd.sh
   ```

3. **用户 push 回结果**
   ```bash
   git add -A && git commit -m "184: 20261106-143000" && git push
   ```

4. **Agent 读取**
   结果在 `<server>/tmp/<时间戳>.log`，Agent 直接读最新文件。

## cmd.sh 约定

- `set -x` 已开启，日志同时包含命令本身和输出，可独立阅读。
- stdout 与 stderr 合并写入日志。
- 日志按时间戳保存、不覆盖，便于对比历次执行。
- 只写非交互式命令；需要 `sudo` 时确认该服务器已免密。
- 命令执行完脚本会打印日志路径。
